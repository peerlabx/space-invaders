Space Invaders

A tiny browser Space Invaders. One file, no dependencies.

Play
----
Open index.html in any modern browser (double-click it), or serve it:

    python3 -m http.server 8000

then visit http://localhost:8000

Controls
--------
Left / Right arrows (or A / D) : move
Space                          : shoot
Enter                          : restart after game over / win

Rules
-----
Destroy all 40 invaders to win. You have 3 lives. The fleet speeds up as
you thin it out, and the invaders fire back. Don't let them reach you.
